Get started

Install SwearSoap

Install both the Windows application and the Chrome extension. The extension is now available on the Chrome Web Store; the Windows application remains an unsigned test build.

Before you begin: This installer is not digitally signed yet. Windows may show a Microsoft Defender SmartScreen warning. Only download it from the official SwearSoap GitHub release.

1. Install the Windows application

  1. Download SwearSoap 0.2.0.
  2. Open the downloaded installer. If SmartScreen appears, confirm that the filename is SwearSoap-Setup-0.2.0.exe before choosing More info and Run anyway.
  3. Complete installation, then launch SwearSoap from the Start menu.
  4. Wait until the SwearSoap window says Ready.

2. Install the Chrome extension

  1. Open SwearSoap on the Chrome Web Store using Chrome.
  2. Select Add to Chrome, then confirm Add extension.
  3. Open Chrome's extensions menu (the puzzle-piece icon) and pin SwearSoap so its soap icon is easy to find.
  4. If YouTube was already open, refresh that tab once.

No Developer Mode or manual folder loading is needed.

Already using a test extension? At chrome://extensions, disable the older unpacked SwearSoap or CleanTube extension before using the Store version. Keep only one copy enabled, then refresh your YouTube tab.

3. Prepare a video

  1. Keep the SwearSoap Windows application open and showing Ready.
  2. Open a normal YouTube video with uninterrupted, ad-free playback.
  3. Select the SwearSoap extension once.
  4. Leave the page open while SwearSoap scans the complete video and creates its filter.
  5. When All clean! appears, select Play clean video.
Advertisement limitation: Videos interrupted by YouTube ads may not clean correctly. YouTube Premium or another ad-free viewing environment avoids this limitation. Let any opening ad finish before starting. If an ad appears during cleaning, select Cancel; do not rely on a filter created while an ad was playing.

Removing SwearSoap

Uninstall SwearSoap through Windows Settings and remove the extension from chrome://extensions. Completed filters and logs remain under %LOCALAPPDATA%\SwearSoap by default so an upgrade does not erase them. Delete that folder manually if you want to remove the local data too.
