# SwearSoap

Official website, downloads, privacy information, and support pages for SwearSoap.

SwearSoap is a Windows application and Chrome extension that locally creates filters to mute selected objectionable language in YouTube videos.

Website: <https://trogdoor.github.io/SwearSoap/>

The current downloadable release is an unsigned pre-release test build. The Chrome Web Store extension is not yet published.
