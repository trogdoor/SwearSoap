SwearSoap support

Start with these checks if SwearSoap is not behaving as expected.

The desktop app does not reach Ready

  • Close other SwearSoap windows and launch it again.
  • Make sure another application is not using SwearSoap’s local service port.
  • Open Diagnostics in the SwearSoap window and record the displayed error code.

The Chrome extension cannot connect

  • Launch the SwearSoap Windows application and wait for Ready.
  • Confirm the SwearSoap extension is enabled at chrome://extensions.
  • Refresh the YouTube tab if the extension was installed or reloaded while that tab was already open.

A video cannot be cleaned

SwearSoap currently supports ordinary YouTube videos. Livestreams, premieres, unavailable/private videos, advertisements, protected media, or a player that has not finished loading may not work. Try another ordinary video before reporting the problem.

Where are the logs?

The rotating diagnostic log is normally located at %LOCALAPPDATA%\SwearSoap\logs\swearsoap.log. It does not intentionally contain captured audio or transcripts, but it can contain video identifiers. Review it before sharing and never post captured audio publicly.

Report a problem

Use the public GitHub issue tracker. Include the SwearSoap version, Windows version, Chrome version, the simple error code from Diagnostics, and the steps that produced the problem. Do not post private media, captured audio, passwords, browser cookies, or ownership tokens.
